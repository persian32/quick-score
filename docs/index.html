학생에게 이 주소를 보내세요

이 주소로 열어야 홈 화면에 quick-score 아이콘이 붙습니다.
script.google.com 주소를 그대로 주면 구글 아이콘이 뜹니다.

어떻게 굴러가나

도우미가 폰에서 입력 → 구글 서버(Apps Script)가 비밀번호와 잠금을 확인 → 스프레드시트에 기록. 선생님은 그 스프레드시트를 열면 끝입니다. 서버 비용 0원, 관리할 서버도 없습니다.

주요 기능

  1. 반별 비밀번호 로그인 — 구글 계정 불필요
  2. 빈칸 = 결석. 인원수에서 자동 제외
  3. 그룹 인원과 회차를 앱에서 직접 조정
  4. 모든 수정이 로그에 기록 — 누가 언제 뭐에서 뭐로
  5. 선생님이 확정한 회차는 수정 불가
  6. 폰 다크모드 자동 대응, 글자 크기 3단계
