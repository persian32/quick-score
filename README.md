# quick-score

그룹별 단어시험 채점 웹앱. 영어 도우미가 폰으로 점수를 입력하면 합계·평균·순위가 자동으로 계산됩니다.

종이 채점표(`참고/원본-채점표.jpg`)를 대체하려고 만들었습니다. 도우미가 하던 더하기·나누기를 없애는 것이 목적입니다.

## 구조

```
[도우미 폰]  ──URL──▶  [Apps Script]  ──기록──▶  [구글 스프레드시트]
 Index.html            Code.gs                    선생님이 그냥 열어서 봄
                       비밀번호 확인
                       잠금 확인
                       로그 기록
```

서버 비용 0원. 구글 계정 하나면 되고, 데이터는 스프레드시트 파일 하나에 전부 들어갑니다.

**합계·평균·순위는 코드가 아니라 스프레드시트 `AVERAGE` 수식이 계산합니다.** `AVERAGE`가 빈칸을 무시하는 성질이 "결석자는 인원수에서 뺀다"는 요구사항과 정확히 맞아떨어져, 결석 판정 코드가 아예 없습니다.

## 기능

- 반별 비밀번호 로그인 (구글 계정 불필요)
- 한 화면에 한 그룹씩 입력, 그룹을 넘길 때 자동 저장
- 빈칸 = 결석. 인원수에서 자동 제외
- **시험은 날짜로 구분.** 첫 점수를 저장할 때 그날 날짜가 자동으로 적힘
- 그룹 인원을 앱에서 조정 (합계가 항상 학생수와 맞게 움직임)
- 시험 줄이 모자라면 알아서 늘어남
- 수정 로그: 누가 언제 어느 칸을 뭐에서 뭐로 바꿨는지 전부 기록
- 시험 잠금: 선생님이 확정하면 도우미는 수정 불가
- **순위는 도우미에게 보여주지 않음.** 시트에 항상 계산되어 있고 발표 시점은 교사가 정함
- 폰 다크모드 자동 대응, 글자 크기 3단계 (선택 기억)
- 홈 화면에 추가하면 전용 아이콘과 이름

## 검사

```bash
node 검사/열계산검사.js      # 그룹 분배 · 열 위치       22개
node 검사/그룹조정검사.js    # ＋/－ 조작 불변식         10개
node 검사/날짜표시검사.js    # 날짜 표시                  5개
node 검사/화면요소검사.js    # 화면·코드·CSS 아귀 맞춤     6개
```

마지막 검사는 문법으로 못 잡는 것을 봅니다 — 코드가 찾는 요소가 화면에 있는지,
화면이 기대하는 CSS 규칙이 살아 있는지, onclick 이 부르는 함수가 정의되어 있는지.

Apps Script 쪽 검사는 설치 후 편집기에서 `runTests` 를 실행합니다 (21개).

## 고칠 때

```bash
python3 도구/미리보기만들기.py    # Index.html 을 고친 뒤
python3 도구/교사화면만들기.py    # 시트 배치를 바꾼 뒤
python3 도구/아이콘만들기.py      # 후보 비교 (/tmp 에 생성)
python3 도구/아이콘만들기.py bars # 아이콘 교체 (bars | medal)
```

`docs/` 를 고치고 push 하면 미리보기 사이트가 1~2분 뒤 자동으로 갱신됩니다.

## 설치

`배포안내.md` 참고. 컴퓨터로 15분, 한 번만 하면 됩니다.

## 보안

구글 로그인 대신 반별 비밀번호를 쓰므로 첫 방벽은 완전하지 않습니다. 대신 **모든 변경이 로그에 남고**, 선생님이 확정한 회차는 도우미가 못 고칩니다. 완전 차단보다 흔적 남기기가 학급 활동에 맞는 균형점이라고 보고 그렇게 설계했습니다.

비밀번호는 스프레드시트 `설정` 시트에 있고, 고치면 즉시 적용됩니다. 재배포가 필요 없습니다.

단, 선생님이 스프레드시트에서 직접 고친 것은 로그에 남지 않고, 잠긴 회차도 선생님은 시트에서 고칠 수 있습니다. 잠금은 도우미를 막는 장치입니다.
