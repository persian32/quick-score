# quick-score

그룹별 단어시험 채점 웹앱. 영어 도우미가 폰으로 점수를 입력하면 합계·평균·순위가 자동으로 계산됩니다.

종이 채점표(`단어왕 채점표.jpg`)를 대체하려고 만들었습니다. 도우미가 하던 더하기·나누기를 없애는 것이 목적입니다.

## 구조

```
[도우미 폰]  ──URL──▶  [Apps Script]  ──기록──▶  [구글 스프레드시트]
 Index.html            Code.gs                    선생님이 그냥 열어서 봄
                       비밀번호 확인
                       잠금 확인
                       로그 기록
```

서버 비용 0원. 구글 계정 하나면 되고, 데이터는 스프레드시트 파일 하나에 전부 들어갑니다.

**합계·평균·순위는 코드가 아니라 스프레드시트 `AVERAGE` 수식이 계산합니다.** `AVERAGE`가 빈칸을 무시하는 성질이 "결석자는 인원수에서 뺀다"는 요구사항과 정확히 맞아떨어져, 결석 판정 코드가 아예 없습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `Code.gs` | 서버. 인증 · 저장 · 로그 · 회차 잠금 · 그룹 조정 · 회차 추가 |
| `Index.html` | 도우미 폰 화면 |
| `Tests.gs` | Apps Script 자체 점검 16개 (`runTests` 실행) |
| `배포안내.md` | **설치 안내. 쓰실 분께 이것만 드리면 됩니다** |
| `docs/app.html` | 홈 화면 아이콘을 달아주는 껍데기. 도우미는 이 주소로 접속한다 |
| `docs/preview.html` | 구글 연결 없이 폰 화면만 확인 |
| `docs/teacher.html` | 스프레드시트가 어떻게 보이는지 |
| `미리보기만들기.py` | `Index.html` 을 고칠 때마다 실행 |
| `교사화면만들기.py` `아이콘만들기.py` | 목업·아이콘 생성 |
| `열계산검사.js` `그룹조정검사.js` | 로컬 검사 |

## 기능

- 반별 비밀번호 로그인 (구글 계정 불필요)
- 한 화면에 한 그룹씩 입력, 그룹을 넘길 때 자동 저장
- 빈칸 = 결석. 인원수에서 자동 제외
- 그룹 인원을 앱에서 조정 (합계가 항상 학생수와 맞게 움직임)
- 회차를 앱에서 추가 (기본 20회차)
- 수정 로그: 누가 언제 어느 칸을 뭐에서 뭐로 바꿨는지 전부 기록
- 회차 잠금: 선생님이 확정하면 수정 불가
- 폰 다크모드 자동 대응, 글자 크기 3단계 (선택 기억)

## 검사

```bash
node 열계산검사.js      # 그룹 분배 · 열 위치       19개
node 그룹조정검사.js    # ＋/－ 조작 불변식         10개
```

Apps Script 쪽 검사는 설치 후 편집기에서 `runTests` 를 실행합니다 (16개).

## 설치

`배포안내.md` 참고. 컴퓨터로 15분, 한 번만 하면 됩니다.

## 보안

구글 로그인 대신 반별 비밀번호를 쓰므로 첫 방벽은 완전하지 않습니다. 대신 **모든 변경이 로그에 남고**, 선생님이 확정한 회차는 아무도 못 고칩니다. 완전 차단보다 흔적 남기기가 학급 활동에 맞는 균형점이라고 보고 그렇게 설계했습니다.

비밀번호는 스프레드시트 `설정` 시트에 있고, 고치면 즉시 적용됩니다. 재배포가 필요 없습니다.
